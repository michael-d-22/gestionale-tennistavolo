# gestionale-tennistavolo

Progetto di apprendimento di Michael (junior developer) per costruire un portfolio: gestionale per una società di tennistavolo (atleti, sessioni, prenotazioni).

## Stack
Java 25, Spring Boot (Maven), Spring Data JPA, MySQL 8.4, API REST, frontend HTML/CSS/JS con fetch.
Package base: com.michaeldamico.gestionale

## Regole di lavoro
- Michael deve saper spiegare ogni riga di codice in colloquio. Prima spiega il concetto, poi proponi il codice.
- Un passo alla volta. Ogni modifica va mostrata con cosa cambia e perché prima di essere applicata.
- I commit li fa Michael, uno per passo completato. Non fare commit né push.
- Non leggere né modificare src/main/resources/application-local.properties (contiene le credenziali). Nessuna password nel codice o nei file tracciati.
- Rispondi in italiano.
